# Project Detail Source

This file is the canonical project-level source for AI explanations in the worker.

How to use it:
- Each project is keyed by its project ID from the portfolio data.
- You can edit any field at any time.
- The AI should prefer these project entries when the user asks about a specific project.
- If a field is empty, the AI can still rely on the existing portfolio summary, but filled fields should always take priority.

Recommended fields:
- current_portfolio_summary
- goal
- problem
- approach
- result
- impact
